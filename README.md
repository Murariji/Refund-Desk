# Refund Desk

An AI-generated micro-drama episode (~60-75 seconds, vertical 9:16).

**Premise:** A city man goes to his late father's village to settle paperwork and finds a strange government counter that refunds regrets.

> Final video: _link to be added_

## What this project shows
- Story and script for the micro-drama format (hook, turn, cliffhanger)
- Character and location consistency using reference images
- Image-to-video generation with multiple AI tools, compared side by side
- Shot-by-shot prompt writing and iteration
- Editing, sound and subtitles

## Folder guide
| Folder | What is inside |
|---|---|
| `assets/references/` | Character sheets, office reference, hero frames |
| `assets/shots/` | Keyframes and generated clips per shot |
| `script/` | Script and shot list |
| `prompts/` | Every prompt used, with the tool and result |
| `logs/` | Tool comparison, failures and fixes, credits spent |
| `final/` | Final export or link to it |
